# CA Firm Website Demos

Five complete, themed demo websites for one fictional chartered-accountancy firm (Mehta & Associates, South Tukoganj, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/ledger` Classic Trust · `/meridian` Modern Animated · `/sage` Warm Approachable · `/granite` Dark Corporate · `/folio` Minimal Editorial
- Each theme: Home, About, Services, Team, Clients, Contact + WhatsApp consultation booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
